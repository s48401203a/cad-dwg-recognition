Generic electrical CAD reader

先读通用图，再按需挂场地包

本工具是通用 CAD 强弱电 3D 读取器：上传 DWG/DXF → 自动解析 → Three.js 预览。 默认 profile 是 generic。百世快运 / 供应链规则是可选场地包，不是仓库默认身份。

默认 generic 可选 express / supply_chain 夹具 tests/fixtures/generic_electrical_min.dxf 严格门 --strict

01

目标与非目标

目标

  • 读取通用强弱电图纸：墙、桥架、摄像头、AP、机柜、配电、照明。
  • 弱电与强电共用同一条解析与 3D 预览链路。
  • 默认不依赖某一客户的编号、月台或炮楼规则。
  • 用公开合成夹具度量读取能力；客户图纸只留本机。
  • 场地规则以 profile 形式可选启用，而不是写死在主路径。

非目标

  • 不是「只服务百世」的内部专盘工具。
  • 不把客户 DWG、DXF、semantic.json、项目目录送进 Git。
  • 不在文档里写内网地址、本机绝对路径或真实场地编号。
  • 不把月台、车尾、炮楼推断当成通用图的必选项。
  • 评测夹具不是施工图，也不替代现场验收。

03

如何跑评测

在仓库根目录执行。公开夹具由 runner 按需生成，不含客户数据。报告写到 exports/eval/（该目录不入库）。

用途：跑公开夹具回归。粘贴位置：仓库根目录终端。基线通过时退出码 0；通用目标缺口只打印 DESIRED_GAP，不因此失败。

公开夹具（默认 generic） 
python tests/eval/runner.py

用途：只评公开夹具，不扫描本机已解析项目。适合开源仓与 CI。

只跑公开夹具 
python tests/eval/runner.py --fixtures-only

用途：通用目标严格门。配电 / 照明 / 墙的 desired 缺口也视为失败，退出码 2。不要把客户图当作严格门输入。

通用目标 --strict 
python tests/eval/runner.py --strict

用途：夹具 + 严格门，排除本机项目扫描。

夹具严格门 
python tests/eval/runner.py --fixtures-only --strict

用途：用可选快运场地包跑同一张合成夹具，对比 generic 与场地推断。不会改仓库默认 profile。

可选场地包对照 
python tests/eval/runner.py --fixtures-only --profile express

无参数时 runner 还会扫描本机 backend/projects/ 做对照，结果只写本机导出目录。 那些项目不能提交。开源评测请加 --fixtures-only。

04

夹具缺口含义

公开夹具是一张合成最小图：图层名为「墙 / 监控 / 网络 / 弱电柜 / 桥架 / 照明 / 配电 / 强电桥架」， 块名为「摄像头 / 无线 AP / 机柜 / 配电箱 / 筒灯」。 缺口表示通用规则还没把这类图元写成语义对象，不是夹具坏了，也不是客户图缺失。

缺口 夹具里有什么 desired 口径 含义
配电 块 配电箱，图层 配电，另有强电桥架连线 power.distribution >= 1 通用读取应识别配电箱 / 配电回路。缺了就说明强电侧还没进设备表。
照明 块 筒灯，图层 照明，文字「照明」 lighting.fixture >= 1 通用读取应识别灯具。不要用快运「车尾射灯」规则去凑数。
墙 闭合多段线，图层 墙，约 20m × 15m structures_min >= 1 通用读取应把建筑墙写成结构对象。不要靠仓库外壳推断来代替。

基线（不加 --strict）要求摄像头、AP、机柜各 1 个且能出 3D。 严格门额外要求配电箱、照明、墙。公开夹具当前两道门都已通过。

05

百世 profile 如何可选启用

仓库默认是 generic。百世相关能力以场地包存在：express（快运）、supply_chain（仓储供应链）。 不启用它们时，解析器不走月台、车尾、炮楼推断。

解析时显式传入

上传完成后，POST /api/parse 带 site_profiles。只读通用图时用 ["generic"] 或不传（后端回落到 generic）。

用途：需要快运场地推断时启用 express。把 <upload_id> 换成实际上传返回的 file_id。不要提交该请求里的客户文件。

启用快运场地包 
{"file_id":"<upload_id>","site_profiles":["express"]}

用途：快运 + 供应链混合场地。

混合场地包 
{"file_id":"<upload_id>","site_profiles":["express","supply_chain"]}

用途：查看当前登记的场地包。

列出 profile 
GET /api/site-profiles
  • 页面上传弹窗仍可勾选快运 / 供应链；那是可选场地包，不是开源默认身份。
  • 评测对照用 --profile express，不要改 cases.yaml 里的默认 generic。
  • 本地若还有 baishi-*.yaml 覆盖文件，只留本机，不入库。
本页自包含，可用 file:// 打开。不要把客户图纸、semantic.json 或本机绝对路径贴进文档。
